# Source inputs

`tscircuit-wordmark-text.svg` is the official tscircuit wordmark.
`J1-S4B-PH-K-S.step` is the connector STEP model used by the original
[RP2040 motor controller v1.0.57](https://tscircuit.com/imrishabh18/rp2040-motor-controller)
fit study. It is required to check the actual JST pin geometry below the PCB.
The numeric component envelopes are preserved in `../reports/component-envelopes.json`.
These are the original inputs from the enclosure study, not a newly measured board.
